# Vector Swarm — macOS Help

Space-invasion shooter — defend the formation

## How to play

Eliminate descending enemy formations, dodge diving attackers, and rescue captured wingmen. Switch Classic/Modern display and Rookie/Pilot/Ace difficulty from the toolbar.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Left / Right or A / D | Move horizontally. |
| Space | Fire; hold for repeat. |
| Return | Start or restart. |
| P | Pause or resume. |
| Save / Load | Use the toolbar controls to save or load a checkpoint. |

## Scores, saves and settings

Save/Load retains score, lives, wave and rescued wingmen in local preferences, restoring at the start of the saved wave. Your high score persists locally.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
